Discord Not connected
How to get a Discord Bot Token:
1. Go to Discord Developer Portal
2. Click New Application, give it a name
3. Go to Bot tab, click Reset Token, copy it
4. Go to OAuth2 → URL Generator, select bot scope + permissions, invite to your server
📱
WhatsApp Not connected
How to set up WhatsApp Cloud API:
1. Go to Meta for Developers, create an app
2. Add WhatsApp product to your app
3. In WhatsApp → API Setup, find Phone Number ID and Temporary Access Token
4. Copy both values and paste below
💼
Slack Not connected
How to get a Slack Bot Token:
1. Go to Slack API Apps, click Create New App
2. Choose From scratch, name it, select workspace
3. Go to OAuth & Permissions, add scopes: chat:write, channels:history, channels:read
4. Click Install to Workspace, copy the Bot User OAuth Token (starts with xoxb-)

Email (SMTP) Not connected
How to set up Email (Gmail example):
1. Go to Google App Passwords (requires 2FA enabled)
2. Create an app password, copy the 16-character code
3. Host: smtp.gmail.com, Port: 587
4. Enter your Gmail and the app password below
Other providers: Outlook (smtp.office365.com:587), Yandex (smtp.yandex.ru:465)
